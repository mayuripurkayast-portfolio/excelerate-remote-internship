 <h1>Dataset Repository</h1>
  <p>This folder contains raw and cleaned datasets used for the DePaul University international student admissions analysis project.</p>

  <h2>Files</h2>

  <h3>1. DePaul_Data.csv</h3>
  <p>Contains the original raw dataset exported from DePaul's admissions CRM, before any cleaning was applied (7,543 records, 80 variables).</p>

  <h3>2. cleaned_data_final.csv</h3>
  <p>Contains the final analysis-ready dataset after the full cleaning pipeline (7,543 records, 36 variables). Used for all EDA, visualizations, and the Power BI dashboard.</p>

  <h3>3. DePaul_Dataset_Spreadsheet.xlsx</h3>
  <p>Contains the documentation workbook with the cleaned dataset, before/after comparison summary, data profile, and cleaning process log.</p>

  <h2>Purpose</h2>
  <p>The datasets in this folder are used for:</p>
  <ul>
    <li>Data Cleaning</li>
    <li>Exploratory Data Analysis (EDA)</li>
    <li>Data Visualization</li>
    <li>Power BI Dashboards</li>
    <li>Internship Tasks &amp; Projects</li>
  </ul>
