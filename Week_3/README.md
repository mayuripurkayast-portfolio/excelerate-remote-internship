<h2>📊 Week 3 – Interactive Dashboard & Insights</h2>

<p>
During Week 3, I worked on creating an interactive <b>Power BI dashboard</b>
to analyze student applications, demographics, program preferences, and
admission trends.
</p>

<h3>🔹 Work Completed</h3>
<ul>
  <li>Created an interactive Power BI dashboard.</li>
  <li>Added KPI cards for Total Applicants, Total Admitted, and Admission Rate.</li>
  <li>Implemented filters and cross-filtering for interactive analysis.</li>
  <li>Analyzed country, program, and intake trends.</li>
  <li>Prepared key insights and recommendations for recruitment planning.</li>
</ul>

<h3>💡 Key Insights</h3>
<ul>
  <li>India contributes the highest number of applicants.</li>
  <li>Computer Science and Data Science are highly preferred programs.</li>
  <li>Fall intake receives the highest number of applications.</li>
  <li>Recruitment sources can be diversified across more institutions and regions.</li>
</ul>

<h3>🎯 Outcome</h3>
<p>
The dashboard helps stakeholders understand application trends and make
better data-driven decisions for recruitment and admission planning.
</p>
